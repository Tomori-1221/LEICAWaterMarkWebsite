# 照片徕卡式底栏水印生成器

一个纯前端的单文件网页应用，为照片添加徕卡风格的底部白边水印，自动读取 EXIF 拍摄参数并生成设备型号与光学参数文字。

**纯本地运行，不联网、不上传任何照片。**

## 功能特性

- **单文件交付** — 全部 HTML / CSS / JS 打包在 `index.html` 中，双击即可运行，无需构建工具、无需本地服务器
- **EXIF 自动解析** — 自动提取焦距、光圈、快门、ISO 与设备型号，无需手动填写
- **品牌归一化** — 内置主流手机与相机厂商映射表，`Xiaomi` → `XIAOMI`、`Apple` → `iPhone` 等
- **实时预览** — 参数改动即时重绘，预览结果与导出结果完全一致
- **批量处理** — 支持多图上传、缩略图切换、一键全部导出
- **高清导出** — 支持 1080 / 2000 / 3000 / 4000 px 宽度，文字清晰不模糊
- **响应式布局** — 宽屏左右分栏，窄屏（<900px）自动上下堆叠
- **零依赖负担** — 仅依赖 exif-js 一个 CDN 库，无框架、无后端

## 快速开始

### 方式一：直接打开（推荐）

1. 下载或克隆本仓库
2. 双击 `WebSiteApp/index.html`
3. 在浏览器中打开即可使用

> 首次使用需联网加载 exif-js 与字体资源，之后浏览器会缓存。
